# Session Workflow

Use this sequence for every implementation session.

## 1) Start

1. Read `docs/STATUS.md`.
2. Pick one scoped objective only.
3. Confirm output files before coding.

## 2) Implement

1. Update or create config templates first.
2. Add or modify code.
3. Keep raw/normalized data boundaries intact.

## 3) Validate

1. Run basic checks for the changed component.
2. Confirm folder placement and naming match standards.
3. Ensure no secrets were added.

## 4) Document

1. Update `docs/STATUS.md` (Completed/In Progress/Next).
2. Update `docs/ROADMAP.md` if phase scope changed.
3. Add targeted notes in `docs/` for new architecture decisions.

## Done Criteria

A task is done only when code, config, and docs are all updated.
