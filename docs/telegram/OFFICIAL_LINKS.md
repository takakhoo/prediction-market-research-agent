# Telegram Official Links

Use these as primary references during implementation.

1. Core API hub: `https://core.telegram.org/api`
2. Bot API: `https://core.telegram.org/bots/api`
3. TDLib intro/docs: `https://core.telegram.org/tdlib`
4. TDLib API methods/classes: `https://core.telegram.org/tdlib/docs`
5. App credentials (`api_id`/`api_hash`): `https://my.telegram.org`

## Usage Rule

1. For MVP ingestion with known channels, default to Bot API docs.
2. For discovery/advanced client behavior, use TDLib docs.
3. If a behavior is unclear, verify against official docs before coding.
